# BuJo Companion Frontend

Next.js frontend for the BuJo Companion application.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

The application will be available at `http://localhost:3000`

## Features

- Image upload and preview
- Groq VLM integration for extracting bullet journal items
- Item management (edit, delete, toggle status, cycle type)
- JSON export functionality
